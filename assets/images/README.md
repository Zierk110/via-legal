# Imágenes de ramas y tipos de proceso

Coloca aquí tus imágenes con estos nombres EXACTOS (o cambia el campo "imagen"
correspondiente en js/data.js si prefieres otros nombres):

- rama-familia.jpg        → tarjeta de la rama "Familia"
- tipo-ejecutivo.jpg      → tarjeta del tipo "Ejecutivo"
- tipo-declarativo.jpg    → tarjeta del tipo "Declarativo"
- tipo-judicial.jpg       → tarjeta del tipo "Judicial"

Recomendaciones:
- Relación de aspecto 4:3 (por ejemplo 800x600px) para que se vean recortadas
  de forma pareja en la grilla, sin importar el tamaño original.
- Formato JPG o WEBP, comprimidas (idealmente menos de 200 KB cada una) para
  que el sitio cargue rápido, sobre todo en celular.
